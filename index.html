GIS / Mapping Built Visit

3D ULPIN Maker

This project extends the government's existing ULPIN scheme (a 14-character ID tied to a parcel's lat/long) into a 3D volumetric ID — appending a structure, floor, unit, and elevation range (Z-range) to the same base code. The Z-range is the key idea: it's what lets the system represent things that have no floor number at all, like air-rights or an elevated metro corridor, and lets it automatically detect when two owners claim overlapping 3D space.

Python GIS 3D Visualization
